# Social-Chem-101 RAG Experiments

Contains the GPT-4o Social-Chem-101 retrieval experiment with exposed intermediate norm findings.

Tracked here:

- scripts for building/retrieving the Social-Chem-101 RAG database
- the reasoning prompt
- compact experiment outputs, metrics, and findings
- database summary metadata

Not tracked:

- raw Social-Chem-101 corpus files
- generated full/project-matched Social-Chem-101 JSONL/CSV databases

Those files are large and should live under `database_local/`, which is ignored by Git.
